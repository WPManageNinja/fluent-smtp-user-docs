# FluentSMTP documentation

FluentSMTP sends WordPress email through the service you already pay for. It is free, and it stays free.

If mail from your site never shows up, start here: [install the plugin](/installing-fluent-smtp/), then [connect an email service](/configurable-email-delivery-providers/). After that, send a test from the **Send Test Email** button in the top bar.
